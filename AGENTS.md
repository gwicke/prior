## Documentation and design docs

- All docs in `doc/`. Brief backlog tracking in `doc/todo.md`.
- General structure for major projects: Focused / tight design doc (<2000 words), only if absolutely
  necessary companion impl doc with more detail.
- Formatting: Simple and editable. 100 chars width, avoid wide tables, minimal line art, use lists
  where tables do not fit.

## Formatting

- Code: Always run `cargo fmt` before commit.
